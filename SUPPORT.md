# Support

## Getting help

- Use GitHub Issues for bugs and documentation issues
- Use GitHub Discussions (if enabled) for general usage questions

## What to include

- Nginx version (`nginx -v`)
- Relevant config snippet
- Reproduction steps
- Expected behavior
- Actual behavior
- Sanitized logs/errors

## Security note

If your report involves a potential vulnerability, follow `SECURITY.md` instead of opening a public issue.
