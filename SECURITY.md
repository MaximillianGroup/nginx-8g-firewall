# Security Policy

## Reporting a vulnerability

Please do **not** open public issues for suspected vulnerabilities.

Report security concerns privately to:

- Repository Security Advisories (preferred)
- Maintainer contact listed in repository ownership settings

Include:

- Affected file/path
- Reproduction details
- Impact assessment
- Suggested mitigation (if available)

## Response expectations

- Initial triage target: within 5 business days
- Confirmed vulnerabilities are prioritized by impact
- Fixes are released with changelog notes when appropriate
